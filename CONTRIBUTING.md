# PLDA Contribution Rules

## Before changes
- Read AGENTS.md and AI_CONTEXT.md.
- Inspect the relevant existing code.
- Identify dependencies and entry points.
- Check Git status.

## During changes
- Preserve existing functionality.
- Prefer minimal, reversible changes.
- Do not invent legal sources or technical behavior.
- Keep secrets outside version control.
- Update documentation when behavior changes.

## Verification
- Run available tests.
- Check syntax and imports when applicable.
- Report what was tested and what was not tested.

## Commit
Use a descriptive commit message.
Do not commit secrets, private case files, or unnecessary databases.
