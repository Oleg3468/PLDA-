# PLDA — правовая база знаний и правила работы с ИИ

PLDA — не веб-приложение и не платная AI-служба. Это GitHub-репозиторий со сводом правил правового исследования, навигацией по первоисточникам, поисковыми процедурами и шаблонами, которые можно использовать с разными ИИ или вручную.

Для чтения справочника не нужны установка, база данных, API-ключ или подписка на конкретную модель. Чтобы ИИ мог работать с содержимым, предоставьте ему доступ к репозиторию или передайте нужные файлы; возможность подключения GitHub зависит от конкретного ИИ и вашего доступа к нему.

> Материалы помогают организовать исследование, но не являются юридической консультацией. Перед использованием проверьте актуальное право, применимую процедуру и сроки в официальных источниках и у квалифицированного специалиста.

## Начало работы

1. Откройте [`AI_START_HERE.md`](AI_START_HERE.md) — короткая карта репозитория.
2. Передайте ИИ [`docs/PROMPT_FOR_ANY_AI.md`](docs/PROMPT_FOR_ANY_AI.md) и материалы по нужной теме.
3. Уточните страну/юрисдикцию, даты событий и вид процедуры. Если данных нет — попросите ИИ отметить пробелы, не додумывая их.
4. Ищите закон и процедуру сначала в официальных источниках из [`docs/legal-library/source-catalog.md`](docs/legal-library/source-catalog.md).
5. Зафиксируйте ссылки, применимую редакцию, сроки и неизвестные обстоятельства по шаблонам из [`docs/templates/`](docs/templates/).

## Рекомендуемая структура дальнейшего пополнения

Новые материалы добавляйте отдельными файлами в `docs/legal-library/`. Для конкретной страны создавайте отдельный страновой раздел только после выбора юрисдикции и проверки ссылок на действующие официальные порталы. Для каждого утверждения о праве указывайте источник, статью/пункт, редакцию, дату проверки и статус источника. Не создавайте «универсальных правил» из закона одной страны.

## Код в репозитории

Папки `app/`, `agents/`, `database/`, `main.py` и `tests/` — сохранённый экспериментальный Python-прототип. Он не требуется для использования правовой базы, не является полноценно готовым юридическим сервисом и не подтверждает, что упомянутые функции работают или покрывают все страны. Основная цель репозитория — правила и проверяемая библиотека знаний, а не запуск приложения.

## Веб-сервис (экспериментальный)

Дополнительно разворачивается локальный веб-сервис: чат-исследование по правилам PLDA, локальный поиск по каталогу официальных источников с датами проверки, генерация черновиков записок и очередь «проверки юриста». Работает без API-ключа (оффлайн-режим); при заданном `PLDA_LLM_API_KEY` использует внешнюю OpenAI-совместимую модель. Инструкция — [`docs/service.md`](docs/service.md). Сервис не является юридической консультацией и автоматически не делает выводов по существу права.

## Обновления

Правовые страницы и процессуальные требования могут меняться. Проверяйте исходную страницу при каждом использовании. В изменениях справочника фиксируйте дату проверки; для серьёзных правовых изменений добавляйте ссылку на первоисточник и краткое описание того, что было перепроверено.

См. [`CONTRIBUTING.md`](CONTRIBUTING.md) перед предложением изменений.

## Безопасность и конфиденциальность

Не публикуйте в публичном репозитории имена, адреса, номера дел, медицинские сведения, пароли, токены или документы с персональными данными. Используйте обезличенные примеры. Не загружайте чувствительные материалы в ИИ, если не проверены условия конфиденциальности и хранения выбранной платформы.

## Язык

Правила и основные пояснения ведутся на русском; названия учреждений, документов и поисковые термины при необходимости сохраняются на языке официального источника. При подготовке перевода отдельно отмечайте, является ли он официальным.
