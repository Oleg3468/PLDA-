# Агентные карточки PLDA и маршрутизация

Карточки `AGENTS.md` в этом каталоге — переиспользуемые промпты для ИИ,
а не автономные агенты и не готовые интеграции. Сначала применяются
правила корневого `AGENTS.md` и `docs/PROMPT_FOR_ANY_AI.md`; документация
базы знаний имеет приоритет над карточками. Веб-сервис PLDA включает эту
маршрутизацию в системный промпт LLM-режима (см. `docs/service.md`).

## Две плоскости анализа

Каждый вопрос раскладывается на плоскость **«физическое лицо»**
(национальное право: обязанности, процедуры) и плоскость **«человек»**
(права человека и международная защита) — методика:
`docs/legal-library/person-statuses.md`.

## Индекс агентов

| Агент | Плоскость | Предмет | Ключевые источники |
|---|---|---|---|
| `national_law` | физлицо | законы и процедуры конкретного государства | официальная картотека юрисдикции |
| `police_law` | физлицо | полиция, остановки, задержания, обыски | национальные законы о полиции |
| `tax_law` | физлицо | налоги, сборы, споры | налоговое законодательство |
| `case_law` | физлицо | судебная практика | официальные реестры решений |
| `human_rights` | человек | основные права, дискриминация, соразмерительность | `docs/legal-library/human-rights.md` |
| `echr` | человек | ЕКПЧ и практика ЕСПЧ | HUDOC |
| `un` | человек | система ООН: договоры, Совет по правам человека, доклады | docs.un.org, ohchr.org; `docs/legal-library/un-ukraine-mobilisation-rights.md` |
| `refugee_law` | человек | беженцы и убежище: Конвенция 1951 г., невысылка, формы защиты | `docs/legal-library/un-ukraine-mobilisation-rights.md`, unhcr.org |
| `research` | общая | поиск и перекрёстная проверка источников | `docs/source-verification.md` |
| `evidence` | общая | документы и доказательства, статусы верификации | `docs/legal-principles.md` |
| `orchestrator` | координация | декомпозиция по плоскостям, маршрутизация, синтез | эта таблица + `person-statuses.md` |

Маршрутизация по темам — в карточке `orchestrator/AGENTS.md`.
Наследие прототипа: папки не подтверждают существование автономных ИИ-агентов,
полного покрытия стран или юридически проверенного вывода; проверяй каждое
утверждение по первоисточнику с датой проверки.
